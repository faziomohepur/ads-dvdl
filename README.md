## Cần bổ sung
- Điền các ô `...` trong bảng giá (`public/index.html`, mục `#bang-gia`).
- Điền thông tin doanh nghiệp ở chân trang và trong `public/chinh-sach.html` (MST, giấy phép vận tải, địa chỉ, email, mốc thời gian hủy/hoàn tiền).
